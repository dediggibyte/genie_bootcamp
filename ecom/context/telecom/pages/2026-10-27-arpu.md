# ARPU

## Definition

**ARPU** = billed revenue / distinct billed subscriptions **in a month**. Always group by `billing_month`: over two months the ratio divides two months of revenue by one set of subscriptions and doubles.

## How to calculate

Use the governed metric view `<catalog>.telecom.billing_metrics` (measure `arpu_sek`) - Genie, dashboards and SQL then all agree.
This query returns the reference value below:

```sql
SELECT MEASURE(arpu_sek) AS arpu_sek
FROM <catalog>.telecom.billing_metrics
WHERE billing_month = DATE'2026-06-01'
```

For a breakdown, select a dimension of the view (e.g. month, region) next to the measure and add `GROUP BY ALL`.

## Reference value

**468.36 SEK** (June 2026, all data, for a user who may see every row; from `data/2026-10-27-expected-answers.json`).

## Common wrong answers

* ARPU over both months without grouping by month.
* Dividing by customers instead of subscriptions.
