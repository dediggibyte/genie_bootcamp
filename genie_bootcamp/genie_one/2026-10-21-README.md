# Genie One knowledge pack — Nordhem Retail Group

These documents give **Genie One** the business context it needs to answer retail questions the way the company
does. They sit next to the gold tables and metric views that the **Genie agent** uses:

| Layer | What it gives | Where |
|---|---|---|
| Gold star schema | Facts and dimensions, column comments, PK/FK joins | `retail_bootcamp.gold` (`notebooks/2026-10-21-03-gold.py`) |
| Metric view (optional) | Governed measures such as Gross Margin % | Unity Catalog, built on `gold.fact_order_line` |
| Genie agent instructions | Vocabulary, rules, SQL expressions, sample questions | `genie/2026-10-21-genie-instructions.md` |
| **Genie One knowledge (this folder)** | Company context, regional methods, promotion policy, KPI definitions, operating policies | `genie_one/` |

## How the documents are written
- **[DATA]** statements are calculated from the bootcamp data (2024-01-01 to 2026-09-30) and agree with the validated
  metrics in `genie_bootcamp/README.md`, e.g. Net Revenue 604,798.15 EUR and Gross Margin 40.84 %.
- **[POLICY]** statements are company rules and market practice. They guide recommendations, but no table stores them.
  Genie One should present them as policy, not as query results.
- Table and column names match `retail_bootcamp.gold` exactly, so Genie One and the Genie agent use the same terms.
- All data and the company are fictional. Regulatory notes (VAT, price-indication rules, withdrawal rights) are
  general context for the bootcamp and not legal advice.

## Loading into Genie One
1. Add the five topic documents (not this README) as knowledge or reference documents in the Genie One space,
   using your workspace's document-upload option. Keep them as separate files so retrieval can find the right topic.
2. Connect the same `retail_bootcamp.gold` tables (or the metric view) as data, so answers combine the
   documents' definitions with live numbers.
3. Test with the questions below and compare against the [DATA] values in the documents.

### Test questions
1. "Which region sells the most per store, and does that include online?" → Norway, ≈ 50,171 EUR per store; East includes online.
2. "Did the 25 % Black Friday discount in 2025 pay off?" → +13.5 % window sales YoY, but promoted margin fell to 23.8 % and broke the Electrolux 20 % floor.
3. "What are our rules for discount depth?" → Max 20 % without CFO approval, brand margin floors, no stacking.
4. "Why is the return rate higher in Scandinavia East?" → It includes online (9.8 %). Stores alone are ≈ 5.9 %.
5. "Which mobile payment do Norwegian stores use?" → Vipps (≈ 26 % of store orders).
6. "What is our gross margin?" → 40.8 %.

## Known data issues that the documents call out
1. Black Friday is defined as 22–30 Nov in the Genie agent instructions, but the promotions run 25 Nov–2 Dec (2024)
   and 24 Nov–1 Dec (2025).
2. PR07 "Winter Outdoor Week" (Category discount) was applied to all brands.
3. PR09 "Loyalty Spring Bonus" was also used by non-members.
4. `dim_date.is_holiday` only flags holidays shared by all three countries. National days are missing.
