## ✍️ How the documents are written

| Convention | Meaning |
|---|---|
| **[DATA]** | Calculated from the bootcamp data (2024-01-01 → 2026-09-30). Agrees with the validated metrics in `genie_bootcamp/README.md`, e.g. Net Revenue 604,798.15 EUR and Gross Margin 40.84 %. |
| **[POLICY]** | A company rule or market practice. It guides recommendations, but no table stores it. Genie One should present it as policy, not as a query result. |
| ⚡ **At a glance** | Each document starts with a summary table of the most-asked facts. |
| 🔤 **Names** | Table and column names match `retail_bootcamp.gold` exactly, so Genie One and the Genie agent use the same terms. |
| 🎨 **Icons** | Emoji mark the topic (🌍 regions, 🏷️ promotions, ↩️ returns…) and status (✅ rule, ⚠️ watch-out, 💡 insight). They are for readability only. |

> ⚠️ All data and the company are fictional. The brand cards are illustrations, not official brand assets.
> Regulatory notes (VAT, price-indication rules, withdrawal rights) are general context for the bootcamp and not legal advice.

## 🚀 Loading into Genie One

1. 📤 Add the six topic documents (not this README) as knowledge or reference documents in the Genie One space,
   using your workspace's document-upload option. Keep them as separate files so retrieval can find the right topic.
   - 🖼️ If your upload option does not render images, the brand cards simply won't show. Every fact on a card is also in the text.
2. 🔌 Connect the same `retail_bootcamp.gold` tables and the metric view `gold.kpi_metrics` as data, so answers combine
   the documents' definitions with live numbers.
3. 🧪 Test with the questions below and compare against the [DATA] values in the documents.
